# 联网判断数据集 v1

300 条人工编写的合成标注数据，依据小模型基线暴露的误判类别构建，不是真实用户日志。标签 true=需要查询外部资料；false=由 RWKV Chat 自答。

- 训练 240 条（120 true / 120 false）。
- 验证 30 条（15 / 15）。
- 测试 30 条（15 / 15），其中 10 条为真实消息结构的多轮语义判断。
- 同一语义组整体分配到一个集合；天气问法、车次问法、店铺营业、股价等相关改写组保留在训练集。
- 当前完成结构、重复消息和组交叉检查，结果见 audit.json；已完成第一版state训练，结果见 docs/search-router-v6-report.md（包含历史基线与当前结果）；不声称达到线上98%。
- 来源与文件SHA256见 manifest.json。已有42条诊断用例用于发现问题与对比prompt，不能作为未见测试集报告。

每条记录包含 id、group、split、messages、needs_search、target、source。target 为 true/false 的训练输出文本。

边界：文本提到天气、今天、搜索或网址，不等于需要联网；要判断当前任务是获取外部事实，还是处理用户已给内容。用户明确禁止联网时标签为false；信息不足但外部数据是必要条件时标签为true，具体问题可由后续流程澄清。

State tuning 的目标是改善任务判断能力，格式合规率单独统计。训练时只能使用train，验证选择使用validation，冻结候选后才使用test验收。

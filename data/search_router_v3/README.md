# 联网判断日常数据集 v3

300条，联网/不联网各150条：240训练、30验证、30测试。

训练集保留v2中的120条基础场景，新增120条覆盖已发现缺陷的场景；验证和测试各新编30条。覆盖日常问答、编程、创作、翻译、天气、版本、价格、出行、门店、新闻、直链、网页/PDF/README阅读、查证、论文、购买建议、多轮上下文、引用文本与指令区分。

重点对照：

- URL指向待读取内容 → true；仅处理已粘贴正文 → false。
- 查可靠依据、搜论文、找下载入口 → true；只设计检索词、写访问代码 → false。
- 多轮追问现任职位、预约、官方资料 → true；上下文指定只翻译或分析给定材料 → false。
- 当前购买建议 → true；仅按用户给的价格和参数比较 → false。

数据为手工构造的合成样本，受此前错误分析启发，不代表真实流量。保留原100条作为已知回归集，未把这些原句直接放入训练集；同类语义有意覆盖。命名场景组不跨集合，但不同集合含同类任务，不将其宣称为完全语义隔离。

训练从基础G1J 1.5B模型的零state开始，仅更新time_state，不继承v1/v2已训练state。保持“对话材料在前，判断要求在后”的协议。验证准确率优先、首目标token NLL次优选择checkpoint，选择完成后才测试。

构建脚本：`scripts/build_search_router_v3_data.py`。`manifest.json`记录文件校验值、数量和来源。
